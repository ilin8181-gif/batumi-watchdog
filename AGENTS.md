# Batumi Watchdog — Паспорт проекта (`batumi-watchdog`)

Облачный сторож доступности и целостности HTML/контента боевого сайта `batumi-expert.ru` (развёрнут на статике **Vercel Edge CDN + Cloudflare DNS**).

## 1. Архитектура
- `watchdog_ci.py` — основной скрипт проверки HTTP-статуса, целостности DOM (`</html>`, отсутствие ошибок рендера, валидность gzip/TLS) с повторным подтверждением падения (`confirm_down()` для защиты от ложных тревог).
- `test_confirm_down.py`, `test_regressions_o1_o2.py` — автотесты сторожа.
- `.github/workflows/` — облачный запуск по расписанию в GitHub Actions.

## 2. Обязательные инварианты и проверка
- **Защита от ложных срабатываний:** не ослаблять двухступенчатую проверку `confirm_down()` и не отправлять тестовые алерты в боевой Telegram без явной необходимости.
- **Проверка после правок:** прогонять автотесты `pytest -q` и сверять поведение на реальном ответе `https://batumi-expert.ru` (`curl --compressed`).
